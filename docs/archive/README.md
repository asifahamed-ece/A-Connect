# Archived Project Documents

These documents represent early research, aspirational roadmaps, reverse-engineering notes on OPPO's proprietary Panta protocol, and early sprint summaries written prior to the current implementation.

> **Note:** The active implementation of A+ Connect uses Electron for the desktop client and Kotlin / Jetpack Compose for the Android companion. None of the Rust, Qt6/Kirigami, or reverse-engineered Panta daemon designs in these archives were built into the codebase.

## Archived Files

* [`development-plan.md`](development-plan.md) — Early project concept proposing a Rust/Qt6 alternative to O+ Connect.
* [`implementation-roadmap.md`](implementation-roadmap.md) — Initial aspirational 14-week milestone timeline.
* [`project-documentation.md`](project-documentation.md) — Early conceptual architecture and module specifications.
* [`protocol-specifications.md`](protocol-specifications.md) — Reverse-engineering analysis of the Panta framing protocol.
* [`WEEKEND-SPRINT-SUMMARY.md`](WEEKEND-SPRINT-SUMMARY.md) — Initial Day 1 sprint summary from early development.
